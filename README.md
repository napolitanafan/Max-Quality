Este repositorio contiene la plataforma web educativa desarrollada por Max Quality. 
El objetivo del sitio es reunir en un solo lugar los fundamentos de la gestión de calidad de software, 
los procesos de desarrollo tradicionales y ágiles, y las distintas metodologías que se utilizan en la industria.

El proyecto está diseñado como una guía de referencia ordenada para estudiantes y profesionales en formación. 
Incluye teoría explicada de forma clara, comparaciones entre diferentes enfoques, modelos de desarrollo, 
herramientas de aseguramiento y casos prácticos con ejercicios resueltos para aplicar los conocimientos.

Este proyecto ha sido desarrollado íntegramente por el equipo de Max Quality como plataforma académica y material de consulta sobre Sistemas de Gestión de Calidad.
